GitHub Actions management

Restart controls currently open the real GitHub Actions page. This dashboard does not store a GitHub token or silently claim to restart anything.

  1. Open Restart controls above and sign in to GitHub.
  2. Open the current running SideBot workflow run and cancel it if necessary.
  3. Use Run workflow on the SideBot Discord workflow page to launch a new run.
  4. Check the run logs for successful Discord startup.
⚠️ GitHub-hosted static pages cannot run a private Python API. For true one-click restart, live status, secure moderation controls, and editing settings here, SideBot needs an authenticated backend deployed on an always-on server. Never paste a GitHub or Discord bot token into this page.
